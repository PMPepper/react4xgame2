This is a WIP 4x stlye strategy game. At the moment, it's more of a tech demo with some core engine functionality to enable high performce, and multiplayer capabilities, but not yet a functional game.

You cna navigate around the game world using mouse with left click& drag, right click for menus, and mouse wheel for zoom. Also, cursors/WASD for scrolling & page up/down for zoom.

# Getting Started

Install using npm install --force (TODO fix dependencies to not require force)

### `npm run start`

Runs the app in the development mode.\
Open [http://localhost:3000/build](http://localhost:3000/build) to view it in your browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.

### `npm run build`

Builds the app for production to the `build` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.\
